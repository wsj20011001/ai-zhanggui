# DESIGN · AI 掌柜 路演

## 画布
1280 × 720，安全区 padding 56px 72px；内容区 1136 × 476（标题 96 + 页脚 36）。

## 色板（4 色，硬约束）
- 背景 `#0B0D14`
- 卡片 `#141826`，描边 `#242A3D`
- 正文 `#F2F4FF`，次级 `#8A90A6`
- 强调 `#6C6CF5`（唯一强调色；数据升级用同色不同透明度）

## 字体
- 中文：思源黑体 / Microsoft YaHei；字号档位 56 / 34 / 22 / 16 / 13
- 英文与数字：Bahnschrift / Arial，数字统一加粗

## 版式规则
- 标题块固定 96px 高：主标题 34 bold + 副标题 15 次级色
- 页脚 36px：左「2026 武汉 1024 · 产业应用赛道」，右「NN / 12」
- 每页至少一个视觉锚点：≥48px 数字 或 ≥40% 内容区的主视觉
- 相邻页版式必须不同（卡片横排 / 左右对比 / 分层堆叠 / 表格 / 时间轴 轮换）
- 留白 ≤ 35%

## 组件
仅用 Box + Text（表格用 Box 模拟），不使用装饰图片；数据可视化用色块条。
