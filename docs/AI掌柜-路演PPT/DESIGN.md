# DESIGN · AI 掌柜 路演（明亮科技风）

## 画布
1280 × 720，安全区 padding 56px 72px；内容区 1136 × 476（标题块 96 + 标题下细线 17 + 页脚 36）。

## 色板（浅底 + 靛蓝强调）
- 画布 `#F6F8FD`（冷白，不用纯白，投影时不刺眼）
- 卡片 `#FFFFFF`，描边 `#E3E8F5`
- 强调底 `#EEF1FE`（浅靛蓝块），描边 `#C9CDF6`
- 正文 `#0C1222`，次级 `#5C6780`，页脚 `#8A93A8`
- 强调 `#4C4DDC`（靛蓝），辅助 `#00B8CC`（青，仅用于图形与徽标点）

## 字体
- 中文：思源黑体 / Microsoft YaHei；字号档位 92 / 34 / 28 / 22 / 16 / 13
- 数字与英文：Bahnschrift / Arial，数字加粗

## 版式规则
- 页头固定：左标题（34 bold）+ 副标题（15 次级）；右侧「● AI 掌柜」品牌徽标
- 标题下方一道 72×3 的靛蓝短线，作为全篇统一的"科技刻度"
- 页脚 36px：左「2026 武汉 1024 · 产业应用赛道」，右「NN / 12」
- 每页至少一个视觉锚点：≥48px 数字 或 ≥40% 内容区的主视觉
- 相邻页版式不同（卡片横排 / 左右对比 / 分层堆叠 / 表格 / 时间轴 轮换）
- 浅底上禁止用大面积纯色条；强调色只出现在数字、徽标、细线与主按钮上

## 组件
Box + Text + Image（附录 A 的界面实拍）。表格用 Box 模拟；数据可视化用色块条。
