## 一、在网页上建一个**空**仓库

### Gitee
1. 打开 https://gitee.com/projects/new
2. 仓库名称：`ai-zhanggui`
3. 路径：`ai-zhanggui`
4. 开源 / 公开：**选公开**
5. **不要勾**「使用 Readme 文件初始化这个仓库」
6. **不要勾** .gitignore 和开源许可证
7. 点创建

> 关键：**必须是空仓库**。勾了 README 就会产生一个初始提交，你 push 时会报 `rejected (fetch first)`，还得多做一步 rebase。

### GitHub
1. https://github.com/new
2. Repository name: `ai-zhanggui`
3. 选 **Public**
4. 同样**不要**勾 Add a README / .gitignore / license
5. Create repository

## 二、拿一个「令牌」（当密码用）

GitHub 从 2021 年起**不允许用账号密码 push**，必须用 Personal Access Token。

### GitHub 令牌
1. https://github.com/settings/tokens → **Generate new token (classic)**
2. Note 填 `ai-zhanggui`，Expiration 选 30 days
3. 勾选 **repo**（整个大项）
4. Generate → 复制 `ghp_xxxxx`（**只显示一次**，先粘到记事本）

### Gitee 令牌
1. https://gitee.com/profile/personal_access_tokens → 生成新令牌
2. 勾选 **projects** 权限
3. 复制生成的字符串

> 用户名就是你的 Gitee/GitHub 用户名，密码位置填这个令牌。

## 三、三条命令

打开 Git Bash（或 PowerShell），把 `<用户名>` 换成你的：

```bash
cd "D:/Develop/Claude Code/AI掌柜"

# 1. 连远程（二选一）
git remote add origin https://gitee.com/<用户名>/ai-zhanggui.git
# git remote add origin https://github.com/<用户名>/ai-zhanggui.git

# 2. 分支改名为 main（现在叫 master）
git branch -M main

# 3. 推上去
git push -u origin main
```

第一次 push 会弹窗要账号密码：

```
Username: <你的用户名>
Password: <粘贴令牌，不是登录密码>
```

> 粘贴时屏幕不显示任何字符，这是正常的，粘完直接回车。

成功后应该看到：

```
 * [new branch]      main -> main
branch 'main' set up to track 'origin/main'.
```

## 四、两个平台都要（可选，1 分钟）

```bash
# 先按上面把 gitee 配好并 push 成功，再追加 github 作为第二个推送地址
git remote set-url --add --push origin https://github.com/<用户名>/ai-zhanggui.git

# 以后每次 git push 会同时推两个平台
git push
```

## 五、常见报错对照表

| 报错 | 原因 | 解决 |
|---|---|---|
| `remote origin already exists` | 已经加过远程了 | `git remote set-url origin <新地址>` |
| `rejected ... (fetch first)` | 建仓时勾了 README，远端有你本地没有的提交 | `git pull --rebase origin main` 然后重新 push |
| `Authentication failed` | 用了登录密码而不是令牌 | 重新 push，密码处粘令牌；还是不行就清缓存（见下） |
| 一直弹窗要求登录、输了也不对 | Windows 记住了错的凭据 | 控制面板 → 凭据管理器 → Windows 凭据 → 删除 `git:https://gitee.com` 或 `git:https://github.com` |
| `fatal: refusing to merge unrelated histories` | 远端有独立历史 | `git pull --rebase --allow-unrelated-histories origin main` |
| 中文文件名显示成 `\344\270\255` | Git 默认转义 | `git config --global core.quotepath false` |
| 每次 push 都提示换行符 | Windows/Linux 换行差异 | 忽略即可，或 `git config --global core.autocrlf true` |

## 六、推完必须检查的三件事

1. **用无痕窗口打开仓库地址**，确认不用登录就能看到文件（这是评委的视角）。
2. **确认没有敏感文件**：仓库里不应该有 `data/` 下的 `.db`、`ai_key.txt`、`secret.key`、`venv/`。
   想再确认一次，本地跑：
   ```bash
   git ls-files | grep -Ei "\.db$|ai_key|secret\.key|^venv/"
   ```
   没有输出就是干净的。
3. **把仓库地址填进材料**：PPT 第 12 页、报名后台的「代码仓库」字段。
