# 功能扩展清单（按「评分收益 ÷ 翻车风险」排序）

> 前提：已有地基 —— 指标层（metrics）、预聚合事实表、语义视图、Agent 工具层（可撤销）、
> 规则洞察、三层预测。所以下面这些不是"造轮子"，是"接线"。

## 一、赛前值得加的（只挑 1~2 个，不要贪）

### ✅ P0-1 经营推演器（What-if）—— 已完成

**一句话**：老板自己拖两个滑块，看"如果这样改，一个月后是什么样"。

| 项 | 内容 |
|---|---|
| 演示话术 | 「AI 给建议，但老板不一定信。所以我们让他自己推：三道菜各涨 5 块，月毛利多 2,300，但按需求弹性客流可能掉 3%，净收益还是正的。」 |
| 实现要点 | 复用 `metrics.q_kpi` 与 `q_dish_quadrant`；前端三个滑块（调价幅度 / 折扣率 / 菜品下架数）；后端纯函数计算，不写库 |
| 成本 | 半天 |
| 翻车风险 | **极低**（不调模型、不写数据、纯算术） |
| 加分点 | 把"AI 建议"升级成"可推演的决策"，创新性和应用价值同时命中 |

### ✅ P0-2 真实数据导入（CSV → 系统）—— 已完成

**一句话**：让评委相信"这套东西能接进我的店"，而不是只能跑演示数据。

| 项 | 内容 |
|---|---|
| 演示话术 | 「老板不用换收银机：把收银系统导出的订单 CSV 拖进来，字段映射一次，之后每天自动增量。」 |
| 实现要点 | 上传 CSV → 列映射界面 → 预览前 10 行 → 导入 orders/order_items → 自动 rebuild 事实表；重复订单号跳过（幂等） |
| 成本 | 半天 |
| 翻车风险 | 低（有幂等保护） |
| 加分点 | 直接回应"落地性"质疑 —— 这比再加一个 AI 功能更能打动产业评委 |

### P1-3 供应商比价

**一句话**：同一食材三家报价，系统告诉你换哪家、能省多少。

| 项 | 内容 |
|---|---|
| 实现要点 | 新增 `suppliers` / `supplier_quotes` 两张表；采购单生成时按最低价推荐；历史价格曲线 |
| 成本 | 半天到一天 |
| 翻车风险 | 低 |
| 加分点 | 成本场景是餐饮老板最痛的点，且能和现有 BOM、采购单串起来 |

### P1-4 手机版老板看板

**一句话**：老板不在店里，手机上也能看那三件事。

| 项 | 内容 |
|---|---|
| 实现要点 | 复用现有 `mobile_base.html` 体系，做一页只读驾驶舱（KPI 卡 + 三件事 + 一键执行） |
| 成本 | 半天 |
| 翻车风险 | 低 |
| 加分点 | "老板视角"比"店长视角"更贴产业场景；手机上演示也更直观 |

### P2-5 每日简报推送（邮件 / 企业微信）

已有 `insights.brief()`，只差一个发送通道。但现场依赖网络与账号配置，**建议做成录屏演示，不要现场发**。

## 二、明确不要现在做的（会拖垮演示）

| 想法 | 为什么不做 |
|---|---|
| 语音问答 | 现场噪音 + 网络延迟，识别错一次就冷场；且和"经营决策"主线关系弱 |
| 拍照 OCR 录菜单 | 准确率不可控，翻车概率最高的一类功能 |
| 外卖/点评平台接入 | 需要账号授权与反爬，合规风险大，两天做不完 |
| 多门店 / 权限体系 | 之前已经砍掉，加了只会让演示路径变复杂 |
| 大模型做预测 | 180 天单店数据撑不起，反而削弱"我们懂边界"的可信度 |
| 自动下单/自动改价 | 触碰"钱"，产业评委一定追问风控；现在"留人确认"反而是优点 |

## 三、赛后路线（答辩时可以说，但别承诺时间）

**1-3 个月：从"单店工具"到"连锁可用"**
- `store_id` 多门店隔离（**未实现**：需全表加字段并回填，预估 15 人日）
- 跨店指标对比：同一道菜在 A 店毛利 62%、B 店 48%，为什么
- 总部集中采购 + 门店收货

**3-6 个月：从"决策"到"执行闭环"**
- 供应商报价单接入，采购从"建议"变成"比价下单"
- 会员召回自动化：分群 → 发券 → 核销 → 效果归因
- 排班建议：客流预测 × 人效 → 班次表

**6-12 个月：从"工具"到"数据网络"**
- 同商圈匿名基准：你的翻台率在同类店里排第几
- 菜品知识库：换季菜单、食材替代方案
- 开放 API：让收银机厂商直接对接

## 四、如果只能加一个

**加 P0-1 经营推演器。**

理由三条：
1. **零外部依赖**：不算模型、不写数据、不依赖网络，现场不可能翻车；
2. **补上叙事缺口**：现在系统是"AI 告诉你该怎么做"，加上它就是"你也可以自己推演"，从"信 AI"变成"用工具"；
3. **成本最低**：指标层和四象限都是现成的，只需要一个页面加一层纯函数。

**时间纪律**：21 号中午前必须完成并跑完 5 个测试；之后只彩排，不加功能。
